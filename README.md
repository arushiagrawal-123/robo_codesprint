📊 YouTube Comment Analyzer

Sentiment & Insight Extraction using NLP

🧠 Overview

The YouTube Comment Analyzer is an NLP-based application developed during CodeSprint to analyze large volumes of YouTube comments and extract meaningful insights such as sentiment distribution, user engagement patterns, and frequently discussed topics.
The project helps creators and analysts quickly understand audience perception without manually reading thousands of comments.

🚀 Features

🔍 Sentiment Analysis (Positive / Negative / Neutral)

🧹 Text Preprocessing

Lowercasing

Stopword removal

Tokenization

Lemmatization

📈 Insight Generation

Sentiment distribution

Most frequent keywords

⚡ Handles large comment datasets efficiently

🧠 ML-driven decision making for content analysis

🛠️ Tech Stack

Python

Natural Language Processing (NLP)

scikit-learn

NLTK / spaCy

Pandas, NumPy

Matplotlib / Seaborn (for visualization)

🧩 Methodology

Data Collection
YouTube comments were collected and stored in structured format.

Preprocessing Pipeline
Comments were cleaned by removing noise (URLs, emojis, punctuation) and normalized for better model performance.

Feature Extraction
Text features were generated using TF-IDF / Bag-of-Words techniques.

Modeling
A supervised ML model was trained to classify sentiments accurately.

Analysis & Visualization
Aggregated results were visualized to highlight audience sentiment trends.
